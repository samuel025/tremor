Tremor

A coin that grows only when a quake affects people.

When the USGS reports a magnitude 6 or larger earthquake that it expects to affect people, and three of five fixed bots agree, Tremor creates a small, capped amount of new supply for a fixed relief list. Nobody votes, there is no admin, and every rule is written into the contract.

How it works

Three steps, all enforced by the contract. Nothing on this page is needed for any of them to happen.

Step 1USGS reports a quake that affects people

Magnitude 6 or more, and the USGS's own estimate of impact (its PAGER alert level) at yellow or higher. Remote or low-impact quakes never count.

Step 2Three of five fixed bots agree

Five bots read the official record on their own. A quake counts only when three attest exactly the same thing. Coins give no say.

Step 3Relief gets new coins

A small amount of new TREM is split between five fixed relief accounts, inside weekly and monthly caps. Holders can also give their own coins to the same five accounts, and a reserve tops each gift up.

Honest limits: this is a testnet prototype with no value. Trust sits in the five bots, here all run by one entrant on one server. See how to check every claim yourself.

Supply only ever grows, and only when a confirmed quake mints for the relief list. Gifts and the donation match move existing coins and create none.

Every quake the contract knows about

Which of the five bots have attested it, whether it counted, and a check against the USGS record made by this page in your browser.

Real quakes the bots have not reported yet

USGS events of magnitude 6 or more, with expected impact of yellow or higher, that the contract has not seen yet. The bots pick these up by themselves once they are old enough.

The relief list

Five fixed accounts, set at launch and never changed. Each mint is split equally. On testnet they are stand-ins: nothing real is donated.

Givers board

Any holder can send their own coins to the relief list. It creates no new coins and gives no say in what counts; the contract only keeps the total each account has given.

The rules, fixed at launch

Read straight from the contract. There is no owner and no method that changes any of these.

How to check me

Run these yourself. Each one is a command in the repository.

git clone https://github.com/samuel025/tremor.git && cd tremor
make test              # Python reference and golden vectors
make conformance       # Rust contract vs Python on random scenarios
make sim               # the simulation scenarios on real data
make replay            # recompute the chain log offline
make verify-onchain    # read the live contract and compare

Tremor is a testnet prototype. It has no value and promises none. Holding it dilutes you when quakes happen. The relief accounts donate nothing real, and nothing here claims real-world impact.
