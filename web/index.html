Tremor

When the earth shakes, this coin does something.

When an earthquake of magnitude 6 or more is confirmed, Tremor creates a small amount of new supply for a fixed relief list. Every mint is capped. Anyone can report an event, anyone can challenge it, and the rules are written into the contract.

How to check me

Do not trust this page. Run the checks yourself.

git clone <repo> && cd tremor
make test              # Python reference and golden vectors
make conformance       # Rust contract vs Python on 200 random scenarios
make sim               # the five simulation scenarios on real data
make replay            # recompute the chain log offline
make verify-onchain    # read the live contract and compare

Tremor is a testnet prototype. It has no value and promises none. Holding it dilutes you when quakes happen. The relief accounts donate nothing real, and nothing here claims real-world impact.
